ERRerror envelope

Every JSON error has the same shape: { "error": { "message", "code", "status" } }. SSE failures arrive as an error event.

StatusCodeMeaning
400INVALID_*Malformed JSON, message or session id
401UNAUTHORIZEDMissing or wrong bearer token
404NOT_FOUND, SESSION_NOT_FOUND, PROJECT_NOT_FOUNDUnknown route, session or project
409SESSION_BUSY, ROOT_PATH_CONFLICT, ACTIVE_PROJECT_LIMIT_REACHED, ACTIVE_LIMIT_BELOW_ACTIVETurn already running, duplicate root, active limit reached, or limit below active count
413BODY_TOO_LARGE, MESSAGE_TOO_LARGEBody > 1 MiB or message > 64 KiB
502HARNESS_*Harness turn failed
503HARNESS_UNAVAILABLE, DATABASE_NOT_CONFIGUREDHarness executable or project database unavailable
504HARNESS_TIMEOUTPer-turn timeout
